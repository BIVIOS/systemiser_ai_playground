Use 'systemiser_writer' agent to write a new systemiser file based on other information you put in the same repo (for example, code you want to see the structure of).

To view and edit Systemiser files register at systemiser.app.

IMPORTANT: to save files in JSON format hold down the 'alt' key when clicking the 'save' button in the Systemiser app. Otherwise, the file will be saved in a different format that is not compatible with the 'systemiser_writer' agent.
